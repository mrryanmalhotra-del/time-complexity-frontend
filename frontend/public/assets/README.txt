Audio Assets for GrowthViz Quiz

This directory should contain three audio files:
- correct.mp3 - Played when user answers correctly
- wrong.mp3 - Played when user answers incorrectly  
- timeup.mp3 - Played when quiz timer expires
- start.mp3 - Played when quiz starts (optional)

You can use any short sound effects (under 2 seconds recommended).

Free sound resources:
- https://freesound.org/
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com/

Note: The app will work without these files, but sounds enhance the user experience.
